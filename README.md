# Space Rangers Quest — «Гнездо пиратов»

Текстовый квест на FastAPI по мотивам «Космических рейнджеров 2».
Ветвящийся сюжет, крафт, репутация, таймер и несколько концовок.

## 🎮 Что умеет

- **Ветвящийся сюжет** — выбор действий влияет на доступные реплики, предметы и финал.
- **Система доверия** к Кацапу — от отношения зависит, что он расскажет и куда пустит.
- **Крафт по рецепту** — «Болотная ряска» готовится из шести ингредиентов с точными пропорциями.
- **Ограничение в 3 дня** — таймер не даёт гулять бесконечно.
- **Несколько концовок** — от провала до успеха, включая ту, которую нужно поискать.
- **Аккаунты** — вход по имени и PIN. Прогресс в SQLite, переживает рестарт сервера.
- **Глоссарий** — статьи о расах, планетах и персонажах, с всплывающими подсказками прямо в сценах.
- **Своя картинка** для каждой сцены (fallback на заглушку, если файла нет).

## 🛠️ Стек

- **Python 3.9+**
- **FastAPI** — веб-фреймворк
- **Jinja2** — HTML-шаблоны
- **SQLite** — хранение аккаунтов и сейвов
- **itsdangerous** — подпись cookie сессии
- **Vanilla JS** — без фреймворков
- **pytest + Playwright + httpx** — тесты

## 🗄️ База данных

SQLite в `data/kr.db`. Две таблицы.

### users

| колонка | тип | описание |
|---|---|---|
| `id` | INTEGER PK | id пользователя |
| `username` | TEXT UNIQUE | логин, регистр не важен |
| `pin_hash` | TEXT | SHA-256 от `username + pin` |
| `created_at` | TEXT | ISO-таймстемп |

### game_saves

| колонка | тип | описание |
|---|---|---|
| `user_id` | INTEGER PK | FK на `users.id` |
| `player_name` | TEXT | имя героя в игре |
| `current_scene` | TEXT | id текущей сцены |
| `money` | INTEGER | кредиты |
| `days` | INTEGER | остаток дней |
| `inventory` | TEXT (JSON) | словарь предметов |
| `trust` | TEXT (JSON) | репутация (Kacap) |
| `flags` | TEXT (JSON) | флаги сюжета |
| `history` | TEXT (JSON) | пройденные сцены |
| `relations` | TEXT (JSON) | отношения с фракциями |
| `updated_at` | TEXT | ISO-таймстемп |

## 🧪 Тесты

```bash
# Установить зависимости (pytest и Playwright уже в requirements.txt)
pip install -r requirements.txt

# Установить браузер для Playwright
playwright install chromium

# Запустить все тесты
pytest

# Только UI
pytest -m ui

# Только API
pytest -m api
